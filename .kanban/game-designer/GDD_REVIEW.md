## 優點

1. **概念出色**: 「扮演蝴蝶改變三國歷史」的核心概念非常有市場差異化。平行時空、蝴蝶效應的敘事框架讓每個玩家的故事都獨一無二。

2. **五大屬性系統**: 智力、武力、運氣、魅力、體力五維度覆蓋了 RPG 經典屬性體系，為不同遊玩風格提供了基礎。

3. **時代定義完整**: 從黃巾之亂(184)到三國歸晉(280)分為7個時代，覆蓋了三國歷史的主要階段，時間跨度合理。

4. **蝴蝶效應標籤設計**: 用 type/impact/target/value 四維度標記事件影響，結構化且可程式化實現，是這個 GDD 最好的設計之一。

5. **無力感防範機制**: 明確提出了「連敗保護」「運氣波動」等玩家體驗保護機制，體現了對玩家情感的考慮。

6. **技能樹規劃**: 雖然標註為「未來版本」，但五條技能路線的規劃顯示了長遠的設計視野。

7. **死亡方式多樣**: 8種死亡方式涵蓋了戰鬥、疾病、意外、暗殺、自殺等，增加了遊戲的不可預測性。

## 具體修改建議 (逐條列出)

### 【骰子系統】

**建議1: 重構判定公式**
```
當前（有問題）: 骰子結果 + 屬性修正值 vs 難度等級
建議改為: 骰子結果 + 屬性修正值 ≥ 難度DC

具體數據:
  簡單: DC=8  (修正值≥2時成功率>50%)
  普通: DC=12 (修正值≥4時成功率>50%)
  困難: DC=16 (修正值≥6時成功率>50%)
  極難: DC=18 (修正值≥8時成功率>50%)
  天命: DC=20 (需要極高修正或運氣特殊效果)

修正值計算: 修正值 = floor(屬性 / 5)
例如: 屬性10→修正+2, 屬性15→修正+3
```

**建議2: 顯示成功率**
每次事件選擇時，顯示預估成功率：
> 「此選項需要武力判定（難度：普通，你的成功率：65%）」

### 【屬性系統】

**建議3: 重新定義體力 (VIT) 用途**
```
VIT 新增用途:
- 健康事件懲罰減免: VIT≥15 時，瘟疫/饑荒懲罰減半
- 可攜帶資源上限: 每點VIT可攜帶1單位額外資源
- 疾病恢復速度: 每年VIT≥10時恢復1點健康
- 戰鬥持續: 多回合事件中，VIT決定額外回合數
```

**建議4: 解決 STR/VIT 重疊**
- STR ≥ 25 解鎖「征戰」（率軍出征）
- VIT ≥ 20 改為解鎖「堅韌」（受傷/疾病懲罰減半，延長壽命）

**建議5: 增加 LCK 主動技能**
- LCK ≥ 18 解鎖「天機」: 每10年可消耗3點LCK，預知下回合事件類型

**建議6: 增加 CHA 中間閾值**
- CHA ≥ 18 解鎖「宴會」: 可舉辦社交活動提升多方關係

### 【蝴蝶效應系統】

**建議7: 改為「標籤+消耗」雙模式**
```
每回合: 從事件池選一個事件，該事件可能附帶蝴蝶效應標籤
觸發時: 
  1. 根據標籤修改蝴蝶效應值（增加或消耗）
  2. 檢查蝴蝶效應值是否達到閾值 → 觸發連帶事件
  3. 連帶事件可以消耗蝴蝶效應值來改變歷史走向

範例:
  - 選擇「助曹操」→ military: 魏 +3
  - 當 魏 ≥ 8 → 觸發「曹操勢力過強」連帶事件
  - 玩家可以選擇「消耗魏+8，觸發諸葛亮提前北伐」
  - 或「不消耗，讓歷史自然發展」
```

**建議8: 提高蝴蝶效應觸發率**
- 所有事件（不只是獨立的「蝴蝶效應事件」類別）都可能附帶蝴蝶效應標籤
- 每個有標籤的事件有15%機率觸發連帶效果
- 蝴蝶效應值 ≥ 閾值的派系，每次觸發都有額外獎勵

### 【事件系統】

**建議9: 增加事件敘述文本規範**
```
每個事件必須包含:
1. 場景描述 (50-100字): 時間、地點、氛圍
2. 角色動態: NPC在做什么，他們說了什麼
3. 玩家的選擇 (3個): 每個選擇有明確的故事代價
   - 選項A: 利益最大化但道德代價
   - 選項B: 平衡但進度較慢
   - 選項C: 道德優先但可能損失資源

範例 (山賊出沒 - 改寫後):
  「你率領家丁回鄉途中，遭遇十餘名山賊攔路。
   為首的山賊頭目手持大刀，冷笑著說：
   『留下買路財，或者留下命！』
   你的家丁們紛紛拔出武器，等待你的命令。

   【選項】
   A. 下令突襲 (武力判定) — 可能獲戰利品，也可能受傷
   B. 談判 (魅力判定) — 可能支付金銀，但損失聲望
   C. 帶家人撤退 — 安全但錯過獲取資源的機會」
```

**建議10: 重寫事件選項的數值設計**
- 刪除所有「逃跑無懲罰」的選項
- 每個選項都有代價: 獲得A的同時必須失去B
- 增加「隱藏後果」: 某些選擇不會立即顯示影響，但會在後續事件中觸發

**建議11: 修復歷史錯誤**
- 附錄A的桃園結義事件描述改為：「中平元年（184年），劉備、關羽、張飛三人於涿縣桃園中結為異姓兄弟...」
- 全面檢查所有事件描述中的年號、官職、地名是否與所屬時代匹配

### 【死亡評價系統】

**建議14: 重設計評價算法**
```
每個維度先正規化為 0-10 分:
- 屬性類 (智略/武勇/福緣/風采/生命力): 平均值/30 × 10
- 聲望: min(峰值/50, 10)
- 財富: min(峰值/100, 10)
- 夥伴: min(數量/10, 10)
- 影響力: 蝴蝶效應總值/50 × 10
- 經歷: min(總事件數/40, 10)
- 姻緣: min(婚姻數/3, 10)
- 成就: min(技能數/8, 10)

總分 = Σ(正規化分數) / 12 (平均值)

評價等級:
- S (天命): ≥ 8.5
- A (傑出): 7.0 - 8.4
- B (優秀): 5.5 - 6.9
- C (普通): 4.0 - 5.4
- D (平凡): < 4.0
```

**建議15: 增加評價矩陣**
根據屬性組合生成不同的結局敘述：
```
高INT + 高CHA → 「名臣謀士，智辯天下」
高STR + 低CHA → 「孤膽猛將，威震一方」
高LCK + 高VIT → 「天選之人，長壽福壽」
低所有屬性 → 「乱世浮萍，隨波逐流」
高蝴蝶效應 → 「你改變了歷史的軌跡」
低蝴蝶效應 → 「你只是歷史的見證者」
```

### 【系統完整性】

**建議16: 增加存檔系統**
```
自動存檔: 每回合結束自動保存
手動存檔: 在以下場景提供存檔選項:
  - 家中/書房 (每回合可用)
  - 酒館/茶樓 (每回合可用)
  - 寺廟/道觀 (可存檔 + 恢復狀態)
  - 戰場 (不可存檔，增加緊張感)
```

**建議17: 修改連敗保護機制**
```
原設計: 連續3次負面 → 第4次強制正面 (有問題)
新設計:
  - 連續2次負面: 下次負面效果減半
  - 連續3次負面: 下次獲得「幸運」狀態，持續2回合
  - 連續4次負面: 觸發「絕處逢生」特殊事件
```

**建議18: 增加轉職/重新定位系統**
```
每10年可選擇一次「人生重新定位」:
- 消耗當前聲望的50%
- 重新分配 5 點屬性
- 保留已解鎖的技能和關係
- 觸發一個「轉折事件」作為敘事過渡
```

### 【難度曲線】

**建議19: 明確定義難度階段**
```
階段 1 (0-15歲): 所有事件無死亡風險，選項懲罰減半
階段 2 (16-25歲): 正常死亡機率，選項懲罰正常
階段 3 (26-40歲): 死亡機率 ×1.5，更多致命選項，蝴蝶效應生效
階段 4 (41-55歲): 死亡機率 ×2，選項懲罰加重，歷史事件密集
階段 5 (56-70歲): 死亡機率 ×1.5，死亡懲罰減半，增加「傳承」事件
階段 6 (71+歲): 死亡機率 ×1，增加「傳承」事件、回憶事件、遺囑事件
```

### 【事件機率分佈】

**建議20: 重構事件抽樣邏輯**
```
每回合流程:
1. 決定事件類型:
   - 歷史事件: 40% (按時代過濾)
   - 隨機事件: 40% (按年齡過濾)
   - 人生階段: 5% (按年齡階段過濾)
   - 稀有事件: 15% (LCK修正)
   - 命運事件: 根據屬性閾值判定

2. 從該類型的合格事件中隨機選一個

3. 判定是否觸發蝴蝶效應:
   - 有蝴蝶效應標籤的事件: 15%機率
   - 觸發後: 增加蝴蝶效應值，可能觸發連帶事件
```

**建議21: 提高命運事件觸發率**
- 改為每種屬性路線在特定年齡階段各有一次「必觸發命運事件」的機會
- 額外1%的全局命運事件判定

## 總結

《三國蝴蝶》擁有一個極具潛力的核心概念——「扮演蝴蝶改變三國歷史」，這個主題既有文化深度又有意義選擇的潛力。然而，目前的 GDD 在**執行層面**存在大量問題，導致實際遊玩體驗可能遠遠低於概念所承諾的品質。

**最優先修復的3件事：**

1. **重寫事件敘述和選項設計** — 這是最核心的。如果事件只是「選A屬性+2 / 選B屬性+1」，那麼這款遊戲和任何其他數值 RPG 沒有區別，無法體現「文字冒險」和「三國歷史」的魅力。每個事件都需要像好的視覺小說那樣有張力、有代價、有故事。

2. **修復骰子系統數學** — 目前的判定公式自相矛盾，且玩家無法預判成功率。這會讓玩家感到困惑和無助，而非挑戰和成長。

3. **增加存檔系統** — 沒有存檔的生命模擬遊戲是不可接受的。這是基本功能需求。

**如果這些修復都能做到，這個遊戲有潛力成為一款8.5/10的優秀作品。** 概念本身非常優秀，只需要在執行層面下功夫。
