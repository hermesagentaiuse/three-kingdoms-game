## 1. 遊戲概述

**三國蝴蝶**是一款三國歷史背景的人生模擬文字冒險遊戲。玩家在三國時代扮演一隻「蝴蝶」，從出生到死亡，你的每一個選擇都會改變三國的歷史走向。

每個玩家都有自己的平行時空——你可能是諸葛亮的軍師，可能是曹操的刺客，可能是平民百姓在戰亂中求生。你的選擇會蝴蝶效應般地改變歷史的走向。

**核心體驗**: 掌控感 × 驚喜感 × 敘事張力

---

## 2. 核心玩法循環

每回合（1 年）的流程：

```
【顯示當前年份 + 歷史背景事件】
       ↓
【系統篩選並隨機選出 1 個事件】
       ↓
【玩家閱讀事件描述】
       ↓
【玩家從 3 個選項中選擇 (A/B/C)】
       ↓
【骰子判定（如果選項需要）】
       ↓
【屬性/資源/關係變化 → 蝴蝶效應標記】
       ↓
【結果訊息顯示 → 玩家選擇「進入下一年」或「結束本回合」】
       ↓
【年齡 +1 → 進入下一回合 → 循環】
```

**關鍵設計原則**:
- 每回合至少有一個**有意義的選擇**（不是只有 A/B 兩選）
- 選擇的結果要有**連帶影響**（不只是 +/-5 數值）
- 偶爾出現**稀有事件**（機率 2-5%）提供驚喜

## 3. 遊戲機制詳細設計

### 3.1 骰子系統

**目的**: 為事件選擇增加不確定性，模擬現實中的運氣成分

**機制**:
```
骰子 = rollDice(骰子數)
例如: d20 表示擲 1-20 的骰子

**判定公式:**
骰子結果 + 屬性修正值 ≥ 難度 DC

修正值計算: 修正值 = floor(屬性 / 5)
例如: 屬性 10 → 修正 +2, 屬性 15 → 修正 +3

難度等級 (DC):
  - 簡單: DC=8  (修正值≥1 時成功率 >50%)
  - 普通: DC=12 (修正值≥3 時成功率 >50%)
  - 困難: DC=16 (修正值≥5 時成功率 >50%)
  - 極難: DC=18 (修正值≥7 時成功率 >50%)
  - 天命: DC=20 (需要修正值≥10 或運氣特殊效果)

每次選擇顯示預估成功率:
  「此選項需要武力判定（難度：普通，你的成功率：65%）」
```

[REVIEW] 骰子系統存在重大數學問題：
1. 成功率與閾值的計算不一致。若判定是「d20 + 修正值 ≥ 難度DC」，屬性≥5(修正+1)對抗普通難度(DC=10)應有55%成功率(需擲10+)，而非50%。
2. 各百分比看起來是拍脑袋給的，沒有公式支撐。
3. 「天命」門檻屬性28幾乎不可達成（最大初始20+成長），但「除非運氣≥25且骰出大成功」——運氣不直接參與骰子判定公式，這條規則邏輯不通。建議改為「天命：屬性≥28，或觸發必中效果」。
4. 玩家無法預判成功率：每次事件只顯示「需要武力/智力」，但不告知門檻是多少，玩家無法判斷「我該硬上還是撤退」。這會導致大量盲擲。

**骰子修正值**:
| 屬性 | 每點修正值 | 作用 |
|------|-----------|------|
| 武力 | +1/5 點 | 戰鬥判定、武力相關事件 |
| 智力 | +1/5 點 | 謀略判定、學問相關事件 |
| 魅力 | +1/5 點 | 外交、招募、說服事件 |
| 運氣 | 大成功/大失敗修正 | 骰出 20 或 1 時觸發特殊效果 |

**特殊骰子效果**:
- **大成功** (骰出 20): 額外效果，通常屬性 +1 或獲得稀有物品
- **大失敗** (骰出 1): 額外懲罰，通常屬性 -1 或觸發負面事件
- **運氣修正**: 運氣 ≥ 20 時，大成功機率提升；運氣 < 5 時，大失敗機率提升

**程式實現**: 使用 `rollDice(sides)` 函數，參數為骰子面數（通常 d20）

### 3.2 屬性系統

**五大屬性**:

| 屬性 | 符號 | 範圍 | 影響範圍 | 成長方式 |
|------|------|------|----------|----------|
| 智力 | 🧠 | 1-30 | 謀略、學問、情報收集、政治決策 | 學習事件、拜師、閱讀 |
| 武力 | ⚔️ | 1-30 | 戰鬥、武力事件、招募將領 | 戰鬥、訓練、尋訪名師 |
| 運氣 | 🎲 | 1-30 | 大成功/大失敗機率、稀有事件觸發、意外生存 | 做善事、信仰、拜拜 |
| 魅力 | ✨ | 1-30 | 外交、招募、說服、婚姻 | 社交活動、贈禮、詩文才華 |
| 體力 | ❤️ | 1-30 | 生存能力、戰鬥持續力、疾病抵抗力 | 醫療、養生、休息 |

[REVIEW] 體力屬性設計過窄：
- 只影響「生存能力、戰鬥持續力、疾病抵抗力」，但「生存」已由年度死亡機率系統覆蓋（VIT≤1必死、高年齡段加成減免），這與「病死」的VIT≤1條件完全重複。
- 「戰鬥持續力」沒被任何事件使用——所有戰鬥事件都是單次判定，沒有持續多回合的戰鬥系統。
- VIT 與 STR 在戰鬥方面重疊，且 VIT≥20 和 STR≥25 都解鎖「征戰」技能（見下方），這讓 VIT 的戰略價值更低。
- 建議：給 VIT 增加獨特用途，如「健康事件免懲罰率」「疾病恢復速度」「可攜帶物品上限（生存資源）」。

**屬性計算公式**:

```
初始屬性分配:
  總點數 = 50 點（玩家自由分配）
  單一屬性上限 = 20 點
  單一屬性下限 = 1 點

出身加成:
  士族: 智力 +3
  平民: 無加成
  商人: 魅力 +2, 運氣 +1
  將門: 武力 +3
  寒門: 體力 +2, 運氣 +1

等級成長:
  每升級 1 級: 隨機選擇 1 項屬性 +1
  升級所需經驗 = 等級 × 50

年度自然衰減:
  50 歲以上: 體力 -1/每 3 年
  60 歲以上: 所有屬性 -1/每 2 年
  70 歲以上: 所有屬性 -1/每年
```

**屬性閾值效應** (當屬性達到特定值時觸發):

| 閾值 | 觸發效果 |
|------|----------|
| INT ≥ 15 | 解鎖「謀略」選項 |
| INT ≥ 20 | 解鎖「兵法」選項 |
| INT ≥ 25 | 解鎖「天下大勢」選項 |
| STR ≥ 15 | 解鎖「比武」選項 |
| STR ≥ 20 | 解鎖「單挑」選項 |
| STR ≥ 25 | 解鎖「征戰」選項 |
| LCK ≥ 15 | 稀有事件觸發率 ×2 |
| LCK ≥ 20 | 意外死亡減半 |
| CHA ≥ 15 | 解鎖「招攬」選項 |
| CHA ≥ 20 | 解鎖「聯姻」選項 |
| CHA ≥ 25 | 英雄見聞事件 |
|| VIT ≥ 20 | 解鎖「抗災」選項 |
|| VIT ≥ 25 | 解鎖「征戰」選項 |
|| VIT ≤ 1 | 死亡 |

[REVIEW] 屬性閾值設計問題：
1. STR ≥ 25 和 VIT ≥ 20 都解鎖「征戰」技能，造成重疊。建議改為VIT≥20解鎖「堅韌」（減半受傷/疾病懲罰），與「征戰」區分。
2. 魅力路線太集中在高端門檻：CHA≥15(招攬) → CHA≥20(聯姻) → CHA≥25(英雄見聞)。建議增加CHA 18解鎖「宴會」（社交加成）。
3. 運氣閾值（LCK≥15/20）只有被動效果。建議增加LCK≥18解鎖「天機」——可消耗LCK點數預知下回合事件。

### 3.3 事件觸發條件

**觸發公式**:
```
事件可顯示條件 = 同時滿足以下全部條件:
  1. 時代匹配: 當前年份在事件時代範圍內 (±5 年)
  2. 年齡匹配: minAge ≤ 當前年齡 ≤ maxAge
  3. 屬性門檻 (如果有): 玩家屬性 ≥ 要求值
  4. 幸運判定 (稀有事件): rollDice(100) ≤ LCK × 2
  5. 狀態檢查 (如果有): 特定 flags/關係值
```

**事件類別與機率分配**:

| 類別 | 佔比 | 觸發方式 |
|------|------|----------|
| 歷史事件 | 30% | 時代+年齡+屬性匹配，固定事件池 |
| 隨機事件 | 50% | 年齡階段+屬性匹配，隨機池 |
| 人生階段事件 | 10% | 嚴格按年齡階段觸發 |
| 稀有事件 | 5% | 高屬性門檻+運氣判定 |
| 蝴蝶效應事件 | 5% | 基於過往選擇觸發的連帶事件 |

[REVIEW] 事件類別機率分配問題：
1. **類別重疊不明**：「歷史事件」(30%) 和「蝴蝶效應事件」(5%) 是分開的嗎？如果一個歷史事件觸發了蝴蝶效應，它是算歷史事件還是蝴蝶效應事件？這會影響玩家對事件類型的預期。建議：蝴蝶效應不是獨立的事件類別，而是所有事件都可能附帶的「額外標籤」。每回合仍從歷史/隨機/人生階段事件中選一個，但觸發時額外判定是否增加蝴蝶效應值。
2. **人生階段事件10%可能太少**：人生階段事件是「嚴格按年齡階段觸發」，這是最能反映角色成長的設計。但10%的佔比意味著玩家可能玩了好幾十年都沒觸發一次人生階段事件。建議改為每個年齡階段至少觸發一次，不佔用其他類別的機率。

[REVIEW] 蝴蝶效應系統設計問題：
1. 「連帶效應觸發」條件只說「當蝴蝶效應值達到閾值時」，但沒說明閾值是多少、在哪裡檢查、多久檢查一次。是每回合檢查嗎？還是事件觸發時檢查？
2. 蝴蝶效應標籤的target列的是人物/派系，但事件中的蝴蝶效應數值（如「military: 黃巾 +3」）用的是非標準派系名。建議統一使用蜀/魏/吳/其他四種派系。
3. 蝴蝶效應只有「增加」沒有「消耗/利用」——玩家累積了魏+8，但無法主動使用這個積累來觸發特定事件。建議增加「蝴蝶效應值可消耗」的機制，讓高積累的玩家能主動改變歷史走向。
4. 5%的蝴蝶效應事件佔比太低——玩家玩了幾十年可能只觸發幾次，無法體驗「蝴蝶效應」的核心快感。建議提高到10-15%，或在每次有蝴蝶效應標籤的事件中都有機會觸發。

### 蝴蝶效應系統 🔑 (核心差異化)

**設計理念**: 玩家的選擇不只是 +/-5 數值，而是真正改變三國的歷史走向。

**[REVIEW] 蝴蝶效應只有增加沒有消耗。玩家累積的蝴蝶效應值沒有用處。需要改為「標籤+消耗」雙模式。**

**[REVIEW] 觸發率太低 (5%)，應該每個事件都可能帶蝴蝶效應標籤。**

**實現機制:**

```
每回合流程:
1. 從事件池中選一個事件（該事件可能附帶蝴蝶效應標籤）
2. 玩家選擇後，蝴蝶效應值增加或消耗
3. 檢查蝴蝶效應值是否達到閾值 → 觸發連帶事件
4. 玩家可選擇「消耗」蝴蝶效應值來改變歷史走向

蝴蝶效應標籤:
  { type: string, impact: string, target: string, value: number }

type (影響類型):
  - "military"    - 軍事力量
  - "political"   - 政治格局
  - "economic"    - 經濟發展
  - "cultural"    - 文化發展
  - "diplomatic"  - 外交關係

impact (影響方向):
  - "positive"    - 正面影響
  - "negative"    - 負面影響

target (影響目標):
  - 歷史人物或派系名稱 (諸葛亮、曹操、孫權、蜀、魏、吳)

value (影響程度):
  - 1-3: 輕微影響
  - 4-6: 中等影響
  - 7-9: 重大影響
  - 10: 歷史轉折點

蝴蝶效應消耗機制:
  當蝴蝶效應值達到閾值時，玩家可以選擇：
    - 「順其自然」: 歷史按原方向發展
    - 「消耗蝴蝶效應」: 用已累積的影響力觸發特殊事件
      例如: 消耗 military:魏 ≥ 8 → 觸發「諸葛亮提前北伐」
      消耗後: military:魏 -= 5，觸發特殊事件

觸發機制:
  - 所有事件（不只是獨立的「蝴蝶效應事件」類別）都可能有蝴蝶效應標籤
  - 每個有標籤的事件有 15% 機率觸發連帶效果
  - 連帶事件可以選擇「消耗」蝴蝶效應值
```

**蝴蝶效應視覺化**:
- 遊戲主頁顯示「蝴蝶效應追蹤器」
- 顯示各派系/人物的力量變化
- 玩家可以看到自己的選擇如何改變歷史
- 結語頁面顯示「你的蝴蝶效應報告」

| **被動** | 武藝超羣 | STR ≥ 15 | 所有戰鬥事件骰子 +2 |
| **被動** | 八面玲瓏 | CHA ≥ 15 | 外交/招募事件成功率 +20% |
| **被動** | 福緣深厚 | LCK ≥ 15 | 大成功機率 +15% |

| **主動** | 外交 | CHA ≥ 20 | 可發起盟約/和談 |
| **主動** | 招攬 | CHA ≥ 15, INT ≥ 10 | 可招募歷史人物為夥伴 |
| **主動** | 征戰 | STR ≥ 25, VIT ≥ 20 | 可率軍出征 |
| **主動** | 醫術 | INT ≥ 20, 華佗事件 | 可治療夥伴/自己 |
| **主動** | 詩書 | CHA ≥ 15, INT ≥ 15 | 可增加聲望 |
| **主動** | 經商 | CHA ≥ 10, LCK ≥ 10 | 可增加金銀 |

[REVIEW] 技能系統設計問題：
1. 技能樹（第251-258行）標註為「可選，未來版本」，但基礎技能已足夠複雜，應優先完成基礎版再談進階。
2. 「醫術」需要「華佗事件」解鎖——這意味著如果玩家沒遇到華佗事件（完全隨機），就永遠無法學醫。這是有設計缺陷的。建議改為INT≥20+特定地點/時代觸發，而非依賴單一隨機事件。
3. 經商技能(CHA≥10, LCK≥10)門檻太低，而所有其他主動技能都需要更高門檻。這讓低屬性玩家也能通過經商賺大錢，打破平衡。
4. 缺少「情報」相關主動技能。既然遊戲有情報系統，應有「間諜」「刺探」等情報技能。

**技能樹設計** (可選，未來版本):

體力路線: 鐵血戰意 → 不死之身 → 萬壽無疆
```

### 3.6 伴侶系統

**伴侶類別**:

| 類別 | 說明 | 獲取方式 |
|------|------|----------|
| 將領 | 武勇過人的將領 | 招募/戰役結識/高魅力 |
| 謀士 | 足智多謀的軍師 | 招攬/高智力事件 |
| 配偶 | 婚姻對象 | 聯姻/自由選擇 |
| 恩師 | 教導你的人 | 拜師事件 |
| 摯友 | 志同道合的朋友 | 社交/共同經歷 |

**關係值系統**:
```
關係值範圍: -100 (死敵) ~ +100 (摯交)

關係變化觸發效果:
  關係 ≥ 80: 解鎖「信任」選項 (可請托重大任務)
  關係 ≥ 50: 解鎖「協助」選項 (戰鬥/事件加成)
  關係 ≥ 0: 正常互動
  關係 ≤ -50: 解鎖「防範」選項
  關係 ≤ -80: 可能叛變/背叛

關係事件:
  每個伴侶有專屬事件（根據關係值觸發）
  關係 > 80 時觸發「義薄雲天」事件

### 3.7 經濟系統

**三種資源**:

| 資源 | 用途 | 獲取方式 | 消耗方式 |
|------|------|----------|----------|
| 金銀 💰 | 購買物品、招募、投資 | 經商、戰利品、賞賜、地租 | 購買、贈禮、建築、戰爭 |
| 聲望 🏅 | 解鎖高端事件、招募人才 | 善行、勝利、才華展現 | 惡行、戰敗、失職 |
| 情報 📡 | 預知事件、戰略優勢 | 情報網、間諜、探索 | 使用情報、建立情報網 |

**資源平衡公式**:
```
初始: 金銀 10、聲望 0、情報 0

年度收支 (根據出身):
  士族: 金銀 +5
  平民: 金銀 +2
  商人: 金銀 +8
  將門: 金銀 +3
  寒門: 金銀 +1

[REVIEW] 經濟系統問題：
1. **初始金銀10太少**：士族每年+5，平民+2。初始10金銀只夠支撐5年（平民）或2年（商人+8，但初始也少）。考慮到事件可能需要花費金銀（如「水利建設」捐款-3、「贈禮」），玩家早期幾乎不可能積累財富。建議初始金銀提高到20-50。
2. **聲望無消耗機制**：聲望只能增加不能減少（除了「惡行/戰敗」這些特殊情況）。這意味著一旦達到高聲望，它就永遠保持在高位。建議增加聲望的自然衰减或「可消耗」用途。
3. **情報系統完全孤立**：情報獲取+1/年或+3/年，消耗-2~-5，但沒有說明情報的實際用途。是解鎖隱藏事件？還是預知敵人行動？需要具體的事件範例說明情報如何影響遊戲。
4. **缺少「裝備/物品」系統**：GDD提到「金銀用於購買物品」，但沒有定義任何物品。玩家賺金銀後可以做什麼？建議至少設計5-10種物品（武器、防具、藥品、古籍等），每件有具體屬性加成。

聲望變化:
  勝利/善行: +3 ~ +10
  戰敗/惡行: -5 ~ -15

情報獲取:
  每年: 情報 +1
  建立情報網: 情報 +3/年
  使用情報: -2 ~ -5
```

## 5. 死亡與評價系統

### 5.1 死亡方式分類

| 類型 | 觸發條件 | 機率 | 蝴蝶效應 |
|------|----------|------|----------|
| **戰鬥陣亡** | 戰鬥事件, STR < 敵方 | 中等 | 軍事 -3 |
| **病死** | VIT ≤ 1 或年齡 + 低 VIT | 高 | 無 |
| **意外死亡** | rollDice(100) ≤ 意外機率 | 低 | 依情境 |
| **暗殺** | 關係 ≤ -80 且 CHA ≤ 10 | 低 | 政治 -5 |
| **自殺** | 聲望 ≤ -50 或關係 ≤ -80 | 極低 | 無 |
| **壽終正寢** | 年齡 ≥ 75 且 VIT ≥ 10 | 隨年齡增加 | 無 |
| **流離失所** | 戰亂中無依無靠, VIT ≤ 5 | 中 | 民生 -3 |
| **餓死** | 金銀 ≤ 0 且饑荒事件中 | 低 | 民生 -2 |

[REVIEW] 死亡方式分類問題：
1. 「病死」的觸發條件是「VIT ≤ 1 或年齡 + 低 VIT」，但「或」後面沒有具體公式。建議改為：死亡機率 = 基礎率 × (1 - VIT/30)，讓VIT連續性地影響死亡風險，而非閾值式的一刀切。
2. 「意外死亡」的「意外機率」沒有定義。是固定的？還是受運氣影響？建議改為 rollDice(100) ≤ (20 - LCK)。
3. 缺少「年老體衰」（高年齡+低VIT但≥75歲）的獨立分類。這個應該和「病死」區分開來，因為它是漸進式的。
4. 「暗殺」需要CHA≤10，這不合理——一個魅力低的將領或謀士被暗殺的機率不一定比高魅力的主公低。建議改為關係≤-80即可能暗殺，與CHA無關。

  觸發條件: rollDice(100) ≤ LCK × 2
  效果: 大量屬性成長或特殊物品
  
隱藏事件 (佔比 1%):
  觸發條件: 複雜的 flags + 屬性 + 關係組合
  效果: 極大蝴蝶效應或特殊技能
  
命運事件 (佔比 1%):
  觸發條件: 特定年齡 + 特定屬性閾值
  效果: 改變遊戲走向的重大事件
```

[REVIEW] 事件概率分佈問題：
1. **機率總和不明**：正常事件95% + 稀有事件3% + 隱藏事件1% + 命運事件1% = 100%。但這四個類別是分層抽樣嗎？還是互斥的？如果是互斥的，那麼「歷史事件」佔95%中的30%是什麼意思？（30%×95%=28.5%？）這容易讓開發者困惑。建議改為：每回合先決定事件類型（抽一個），再從該類型中選一個具體事件。
2. **稀有事件機率矛盾**：稀有事件佔比3%，但觸發條件「rollDice(100)≤LCK×2」在LCK=15時是30%機率，遠高於3%。這意味著高運氣玩家的稀有事件觸發率是低運氣玩家的10倍，但設計意圖是「5%的稀有事件佔比」。建議：改為全事件池中設定一個稀有事件標籤，每回合以5%基礎機率抽到，再乘以LCK修正。
3. **命運事件1%太低**：三國時代覆蓋近100年，1%機率意味著平均100回合才觸發一次。但玩家一生通常只有50-80回合。這意味著超過60%的玩家永遠不會觸發命運事件。建議改為5%，或改為「按年齡階段有1次強制觸發機會」。

### 6.3 難度曲線

```
難度階段:
  階段 1 (0-15 歲): 簡單 — 保護性事件為主
  階段 2 (16-25 歲): 普通 — 選擇開始影響未來
  階段 3 (26-40 歲): 困難 — 蝴蝶效應開始顯現
  階段 4 (41-55 歲): 困難 — 重大歷史事件密集
  階段 5 (56-70 歲): 普通 — 影響力下降，但仍有選擇
  階段 6 (71+ 歲): 簡單 — 安享晚年或善終
```

[REVIEW] 難度曲線設計不足：
1. **「困難」的定義模糊**：階段3標註「蝴蝶效應開始顯現」，階段4標註「重大歷史事件密集」。但這些不會自動增加遊戲難度。建議明確定義：「困難」階段意味著更多致命選項、更少保險選項、更高的死亡機率。
2. **缺少動態難度調整機制**：目前的曲線是完全基於年齡的線性設計。但不同屬性路線的體驗完全不同——高INT玩家的政治事件在40歲時可能比20歲時更複雜（涉及更多派係），而高STR玩家的戰鬥事件在任何年齡都可能致命。建議加入「動態事件池複雜度」機制。
3. **階段6（71+歲）的「簡單」可能無聊**：老年人只剩「安享晚年」事件，但玩家可能已經玩了70回合，這個階段會顯得重複和乏味。建議增加「傳承」事件——選擇弟子、留下遺囑、寫回憶錄等，讓晚年也有選擇的意義。

## 7. 玩家體驗設計

### 7.1 成就感設計

**即時回饋**:
- 每次屬性成長都有視覺回饋（數字跳動 + 音效）
- 每次蝴蝶效應觸發都有標記更新
- 每次解鎖技能都有動畫效果

**階段性里程碑**:
- 10 歲: 「你已經度过了童年！」
- 20 歲: 「你正式踏入社會！」
- 30 歲: 「三十而立！你的名聲開始傳開。」
- 40 歲: 「四十不惑！你已成為時代的見證者。」
- 50 歲: 「五十知天命！你的經驗已經豐富。」
- 60 歲: 「六十耳順！你的智慧已臻化境。」
- 70 歲: 「七十從心所欲！你是時代的長輩。」
- 死亡: 評價頁面

### 7.2 無力感防範

**設計原則**:
1. **永遠提供選擇**: 即使是最壞的情況，也要有 3 個選項
2. **小勝利累積**: 不要讓玩家連續遭遇 3 次以上挫敗
3. **運氣緩衝**: 低運氣玩家也會偶爾觸發好事件
4. **蝴蝶效應賦能**: 玩家的選擇永遠有意義，即使結果不完美

**防範機制**:
```
連敗保護:
  如果連續 3 次事件結果都是負面 → 第 4 次強制觸發中性/正面事件

[REVIEW] 核心機制遺漏與設計問題：
1. **完全沒有存檔系統**：這是一個跨越一生的遊戲（可能80回合），每回合一年。如果瀏覽器崩潰或玩家關閉頁面，所有進度丟失。必須設計自動存檔（每回合）和手動存檔（在特定地点如家中、書房）。
2. **連敗保護機制有問題**：強制在第4次觸發正面事件是「強制」的——它不依賴玩家選擇，這會打破「選擇有後果」的核心體驗。玩家會意識到「反正第4次一定好」，於是刻意讓前三次失敗。建議改為：第4次的負面效果減半，或增加一個「幸運」狀態，持續2回合。
3. **缺少「重新開始」的途徑**：GDD中沒有提到是否可以重新生成角色、調整屬性分配。如果玩家開始玩5年後發現屬性分配不佳，他會很痛苦。建議在每10年提供一次「轉職/重新定位」機會，允許重新分配少量屬性點。

運氣波動:
  低運氣玩家每 10 年觸發 1 次小幸運事件

選擇重要性:
  每個選擇至少影響 1 項蝴蝶效應值
  玩家永遠可以看到自己選擇的長期影響
```

### 7.3 驚喜元素

**稀有事件設計**:
- 「天降異象」: 可解鎖特殊技能
- 「仙人指路」: 隨機屬性 +5
- 「古書現世」: 解鎖隱藏技能

**隱藏結局**:

- 「隱居高士」: 一生不涉政事，但德行高尚

- 「平凡幸福」: 雖然平凡但家庭幸福、長壽終老

## 11. 系統完整性

### 11.1 存檔系統

**[REVIEW] 原文檔完全缺少存檔系統。80回合的生命模擬遊戲沒有存檔是不可接受的。**

**自動存檔:**
- 每回合結束自動保存
- 保存在 `localStorage` (前端) 或 `IndexedDB`

**手動存檔:**
以下場景提供存檔選項:
| 場景 | 存檔 | 額外效果 |
|------|------|----------|
| 家中/書房 | ✅ | 可恢復 1 點 VIT |
| 酒館/茶樓 | ✅ | 可獲取情報 |
| 寺廟/道觀 | ✅ | 可恢復 VIT |
| 戰場 | ❌ | 增加緊張感，不能存檔 |

**存檔格式:**
```json
{
  "timestamp": 1718726400,
  "year": 200,
  "age": 25,
  "player": { ... 完整玩家狀態 ... },
  "butterflyHistory": [ ... ],
  "saveSlot": 1
}
```

**存檔槽位:** 最多 5 個手動存檔槽位 + 1 個自動存檔

### 11.2 物品/裝備系統

**[REVIEW] 經濟系統缺少物品和裝備，金銀用途不具體。需要增加此系統。**

### 11.3 連敗保護機制修正

**[REVIEW] 原連敗保護強制觸發正面事件，會鼓勵玩家故意失敗。已修正為漸進式保護。**

```
原設計（有問題）:
  如果連續3次事件結果都是負面 → 第4次強制觸發正面事件
  問題: 玩家會故意選擇壞選項來「刷」好事件

新設計（漸進式保護）:
  連續2次負面: 下次負面效果減半
  連續3次負面: 下次獲得「幸運」狀態，持續2回合
  連續4次負面: 觸發「絕處逢生」特殊事件
```

### 11.4 人生重新定位系統

每 10 年可選擇一次「人生重新定位」:
- 消耗當前聲望的 50%
- 重新分配 5 點屬性
- 保留已解鎖的技能和關係
- 觸發一個「轉折事件」作為敘事過渡
